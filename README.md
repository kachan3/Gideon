# Crónicas de Gideon — Base de Conocimiento

> Este es el repositorio conectado de Gideon; desde aquí puedo tener un control de versiones de los cambios y mantener un historial firme que otras plataformas no permiten. *(Texto original del README.)*

Reestructurado el **2026-07-02** como base de conocimiento modular. El documento maestro monolítico (`Gideon Core.md`) fue dividido en módulos por pilar; el original íntegro está en `99_Archivo/`.

## Mapa del repositorio

| Carpeta | Contenido | Regla |
|---|---|---|
| `00_Proyecto/` | Gobierno: instrucciones del asistente, índice general, vocabulario oficial, informe de reestructuración | Leer primero |
| `01_Filosofia/` | Directivas de diseño (filosofía de la obra, reglas directivas de la magia) | Enmarcan todo lo demás |
| `10_Reglas/` | **Motor de reglas puro**: resolución 1d100, magia, estados | No depende de contenido |
| `20_Contenido/` | Lo que usa las reglas: creación de personaje, sendas, equipo, talentos, ritos | Depende de `10_Reglas` |
| `30_Propuestas_No_Ratificadas/` | Diseños propuestos sin canonizar (XP/Feats, Muerte y Sucesión, Entrenamiento v1/v2) | No es canon |
| `40_Mundo/` | Lore: cronología, cosmología, personajes, geografía, facciones, criaturas | Contenido narrativo |
| `50_Herramientas/` | Hojas de cálculo: ficha automática (fuente **X**) y simulador de tiradas | X = máxima autoridad en mecánicas |
| `90_Control/` | Control de canon: incongruencias (§20), fórmulas canónicas (§20.bis), esqueletos (§21), Falencias serie B, análisis | Estado del proyecto |
| `99_Archivo/` | Originales, backups y derivados obsoletos. **Nada se borra.** | Solo lectura |

## Fuentes y jerarquía (sin cambios)

**X** (hoja de cálculo) > **T** (Trello) > **M** (1d100.docx) > **L** (Lore.docx); las excepciones canonizadas por Hassan en sesión priman sobre todo.
