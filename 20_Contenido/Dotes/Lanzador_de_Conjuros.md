# Lanzador de Conjuros

Otorga acceso pleno a las reglas de **Spellcasting Modular** (§13.6). Sin este dote, un personaje **no puede lanzar conjuros**. Al obtener este dote, el personaje debe elegir una **Epifanía** (ver [Epifanía Original](../Senda_Arcanista/Arcanista_01_Habilidades_Insignia.md)). La acción asociada se consulta en [Denme Algo de Tiempo](../Accion_Denme_Algo_de_Tiempo.md).

> El acceso a Spellcasting Modular forma parte de **Herencia Arcana**. Si otra fuente concede una capacidad equivalente, no genera XP inicial ni una concesión adicional.
